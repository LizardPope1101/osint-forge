# OSINT Forge 0.8.1

OSINT Forge 0.8.1 is a focused patch release for the v0.8 correlation and
confidence line. It preserves the v0.8 product contract and ships the
concurrent case-edit protection validated after v0.8.0.

## Fixed

- Serialize concurrent target additions to the same case with a per-case
  advisory lock.
- Preserve all unique updates when multiple workers modify one case at nearly
  the same time.
- Prevent silent lost updates while retaining atomic, owner-only case files.

## Validation

The deterministic regression fixture performs 16 simultaneous unique case
additions and verifies that every addition survives. The exact release change
was validated by hosted CI on Python 3.10, 3.11, 3.12, and 3.13, plus clean
Debian stable and Ubuntu 24.04 installation and integration jobs.

## Scope

This release contains no v0.9 feature work. Automatic provider selection using
expected information gain and automatic verification/enrichment plugin
dispatch remain explicit v0.9 commitments.

For the complete v0.8 feature set, see the [v0.8.0 release notes](v0.8.0.md).
