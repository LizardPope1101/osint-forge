# OSINT Forge 0.8.0

OSINT Forge 0.8.0 adds the correlation and confidence layer committed in the
roadmap. This repository document describes the release candidate; it does not
claim that a tag or hosted release has been published.

## Highlights

- Import versioned search-provider JSON with
  `osint case observe CASE PROVIDER INPUT`. Forge validates and preserves the
  evidence offline; it does not fetch results or execute the provider.
- Execute an explicitly selected, versioned argv-based provider adapter for
  compatible case seeds with `osint case search CASE ADAPTER`.
- Inspect a deterministic, provenance-linked graph with
  `osint case intelligence CASE` or `--json`.
- Correlate provider observations without dropping source history,
  contradictions, or underlying-source dependence. Case seeds and plugin
  candidates remain available in their existing entity/report views.
- Represent evidence-backed relationships and separate observation,
  relationship, identity, and currentness confidence.
- Keep verification status distinct from confidence and disclose when a
  compatible verification tool is unavailable or failed.
- Classify temporal state independently from identity support.

Provider evidence is the primary discovery layer in this release. Existing
plugins continue as optional verification and enrichment sensors. Automated
inferences expose their evidence, method, timestamp, source-independence
assumptions, contradictions, contribution, and rationale; they remain separate
from analyst-confirmed intelligence.

## Compatibility and boundaries

Existing case, plugin, workflow, reporting, integrity, and export behavior is
preserved through additive versioned contracts. Provider ingestion is strict
and fail-closed. Owner-only case permissions and conservative shareable
redaction extend to the new evidence and graph data.

Version 0.8 does not automatically select providers, run newly applicable
plugins, recursively pursue discovered entities, or produce the final v1.0
profile. Controlled recursive discovery and its budgets and stopping rules
remain scheduled for v0.9.
